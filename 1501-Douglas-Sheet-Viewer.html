      How to use this viewer
      1. Coordination puts every system on one plan. Sheets shows the nine owner sheets.
      2. Pick a level, then use Go to room to zoom to one room.
      3. Show picks the layers for one trade. The Layers checkboxes turn single layers on and off.
      4. Numbered pins are open items. Tap a pin, or its line in the list, to read the note. Tap the note to close it.
      5. + and − zoom. Drag the plan to move it. Fit shows the whole level.
      6. On a phone, Controls ↑ takes you back up to the controls.

      Reading the plan
      • A number inside a light is its switching zone. Lights with the same number switch together.
      • Switch labels (S 4, V, F, U and so on) are explained in the legend on each lighting sheet and on Owner E.
      • Furniture fades when a system layer is on, so the system reads against the walls.
      • Red text on the plan is an owner note or a clearance to keep.
      • North is up on every plan.
